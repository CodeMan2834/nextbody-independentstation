网站后台操作手册

每次只改一组内容，发布后检查电脑和手机页面。

STEP 2修改
STEP 3发布

登录后台

  1. 点击上方 打开后台。
  2. 依次点击 进入 GitHub 登录、使用 GitHub 登录，使用自己的账号登录。
  3. 在左侧选择栏目，再点击内容条目。

首次使用：把 GitHub 用户名发给网站负责人，接受权限邀请后再登录。

找到要改的内容

要改什么后台位置操作
首页文案 / 轮播首页内容 → 首页主要内容展开对应板块修改。轮播在“首页首屏”中添加、删除或拖动排序。
产品介绍 / 参数产品管理 → 产品目录 → 产品列表展开 X60、OneScan 或 F20，修改文字、图片、参数和下载文件。
应用案例应用案例 → 案例列表点击新增，填写文字与图片；拖动调整顺序。案例编号保持唯一。
邮箱 / 导航 / 按钮全站设置 → 联系信息与社交账号修改对应字段。导航和咨询按钮请同时核对名称与链接。
联系页等页面文字独立页面 → 页面文案展开对应页面修改。隐私政策、服务条款经负责人确认后发布。
搜索结果标题 / 摘要全站设置或产品管理 → 搜索引擎展示（SEO）全站设置控制首页；产品内配置控制对应产品页。留空使用默认值。
公司、解决方案与博客公司 · 解决方案 · 博客修改公司介绍及解决方案；在博客文章中新增条目，填写唯一页面标识、封面、摘要和正文，选择“已发布”后保存。选择“草稿”则不会公开显示。
查看访问统计访问分析使用 GitHub 登录，选择日期、渠道或产品，点击“应用筛选”；左侧切换来源、内容、模块或询盘转化。显示“等待数据库接入”时尚无真实数据，不代表访问量为零。
生成推广链接访问分析 → 推广链接选择目标页面，填写英文来源、媒介和活动名称，生成并复制链接。不要填写客户姓名、邮箱等个人信息。

新增产品、修改页面网址、调整布局或账号权限：联系技术负责人。

更换图片和视频

图片 / 下载文件

点击对应字段 → 上传文件 → 选中文件。图片使用 JPG、PNG 或 WebP，说明书使用 PDF。

视频

视频字段选择 MP4，并设置封面图。轮播每条先选“图片”或“视频”，再选择对应素材。

发布后检查：图片中的设备和 Logo 显示完整；视频能播放；下载链接能打开。

发布与检查

  1. 核对修改，点击顶部 发布 → 立即发布。
  2. 看到 本次内容已保存 后，等待网站更新。有部署查看权限时，确认对应版本为 Ready。
  3. 打开 正式网站 ↗，刷新页面，检查电脑和手机效果。
  4. 继续修改：点击 重新载入，继续维护。结束工作：点击 退出 / 结束编辑。

保存成功后，官网需要等待部署更新。修改联系邮箱后，另提交一条测试询盘并确认收件。

遇到问题

看到的问题怎么处理
无法登录 / 无权限重新登录 GitHub；仍不成功，将账号用户名和错误截图发给负责人。
发布失败 / 红色提示按提示修正字段后重新发布；仍失败，保留文字和截图，联系技术负责人。
保存后官网没变等待更新后刷新。仍没变化，提供修改栏目、发布时间和截图给技术负责人。
图片不显示 / 视频打不开重新选择对应素材、核对文件类型，再发布并检查。
询盘邮件没收到检查 info@nexbodyfit.com 及垃圾邮件；仍未收到，记录提交时间并联系负责人。
已发布内容需要恢复联系技术负责人，说明要恢复的页面、内容和时间。
