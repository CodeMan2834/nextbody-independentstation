# NEXBODY 访问分析：预开发与待接入事项

主工程：`E:\nexbody\nextbody-independentstation`。

当前阶段只完成本地代码与验收。没有创建 Turso 账号或云数据库，没有启用正式采集，没有推送部署。默认 `ANALYTICS_ENABLED=false`。

## 已准备

- 中文看板 `/admin/analytics.html`：总览、来源、内容、模块、顺序转化、UTM 链接生成器；日期、设备、渠道、产品会话筛选；CSV；可见时每五分钟刷新。
- 同源、同意后采集；拒绝、DNT、GPC、撤回均停止可选行为采集。先记录页面访问，再按核心区域可见 50% 且持续一秒记录曝光。点击会补齐该模块的曝光。
- 本次会话来源使用 UTM 优先，其次外部域名；站内跳转不改写原入口。UTM 只允许非个人英文标记；不读取表单内容，不记录完整 URL 查询或原始 IP。
- 30 分钟无被记录的活动后结束访问会话；不做跨设备识别。页面切换使用 pathname 事件，避免两次初始化重复记浏览。
- 成功询盘只能由服务端在邮件服务确认接收后写入。只关联自愿统计且有效的会话；无同意上下文的询盘不进入统计，网站询盘本身照常处理。统计故障不会将已成功提交变成失败。
- GitHub 登录完成仓库写权限验证后，生成加密 HttpOnly / Secure / SameSite Cookie；看板接口另做权限检查，成功结果最多缓存五分钟。看板会话八小时到期。退出清除浏览器会话，不撤销 GitHub OAuth 应用。
- 四张表：访问会话、原始事件、按会话与维度汇总的日数据、短期限流记录。事件 ID 去重与汇总触发器在同一写事务中处理。
- 明细 90 天，汇总 365 天；带鉴权的维护接口和脚本已准备。
- 一致性 JSON 快照备份、恢复到新空库的工具；拒绝覆盖已有统计表。
- 本机演示必须显式显示“演示数据”，真实本机读写显示“本地验收 · 非线上统计”。线上不开放演示开关。没有数据库时显示未连接，而非零访问量。

## 账号就绪后再做

1. 公司账号创建免费 Turso 数据库；选择与网站函数位置匹配的可用区域，核对届时的套餐与限制，不自动升级付费。
2. 将数据库地址和受限访问凭据配置进 Vercel Production。密钥不要放在聊天、公开代码或 `NEXT_PUBLIC_*` 中。
3. 配置独立随机 `ADMIN_SESSION_SECRET`（至少 32 字符），以及维护任务使用的独立 `CRON_SECRET`（至少 32 字符）。同一生产部署内保持稳定。
4. 在安全的本地终端或 CI 环境，以进程环境变量传入数据库凭据，执行 `npm run analytics:migrate`。迁移可重复执行，不清空已有记录；后续表结构升级需新增迁移。
5. 保持 `ANALYTICS_ENABLED=false`，先验证远程迁移、写入、读取、导出和备份恢复。
6. 完成真实运维账号的看板登录、无权限拒绝、退出和会话到期验收。CMS 与看板共用 GitHub 认证入口，但 Cookie 与数据权限在服务端验证。
7. 配置每日清理调度。`config/analytics-vercel-cron.example.json` 仅为样例，当前未自动注册任务；合并到实际 `vercel.json` 前核对平台套餐。表达式为 UTC 每日 02:15，即北京时间 10:15。
8. 选定独立的备份保存位置及执行环境，配置每日备份与失败通知，再完成一次恢复演练。备份脚本已完成，云端定时备份和告警尚未建立。
9. 检查 Turso 控制台的存储、读写额度，确定用量阈值和通知接收人。数据库业务报表不等于服务商账单用量；当前未接入服务商用量告警。
10. 开启 `ANALYTICS_ENABLED=true`，推送部署。正式页面实际同意、拒绝、点击、SPA 跳转、下载、询盘全流程验收；最后恢复本轮测试数据并确认生产开始统计的时间。

## 本地检查命令

```text
npm test
npm run build
npm run analytics:migrate
npm run analytics:backup -- <项目外的新文件路径.json>
npm run analytics:restore -- <备份文件路径.json>
npm run analytics:cleanup
```

数据库脚本读取进程环境变量，不会自动读取 `.env.local`。本地文件 URL 只能用于本机开发与测试；生产应用拒绝文件数据库。恢复必须指向新的空数据库；恢复失败后不要将该目标直接切为正式连接。

## 指标口径

- 会话不等同于人数。浏览量包括刷新和不同页面的站内切换；同一路径查询参数变化不再计一次浏览。
- 所有报表按北京时间日期汇总。模块按“页面 + 固定模块标识”区分，修改页面文案不会改变模块标识。
- 曝光与点击率按会话去重；总点击单独展示。自动播放不计主动视频播放。
- 产品筛选是“在所选范围内浏览过该产品的会话”，会汇总这些会话范围内的其他行为，不等于只统计该产品页面。
- 转化队列为所选范围内开始的会话，按产品浏览 → 随后联系页 → 随后成功询盘排序，步骤也必须在范围内。直接联系的询盘会进入总询盘数，不强行进入产品漏斗。
- 原始访问查询不足或未授权时，不把未采集数据当作零。来源未知、浏览器拦截、拒绝可选统计、机器人过滤、接口限流等均会影响覆盖率。
- 上期为等长日期区间。超出保留期或上线前无历史数据时，显示上期无记录。

## 限制

当前数据库采用 SQLite/libSQL 本机完成语义测试；尚未验证实际 Turso 网络延迟、区域、套餐、凭据、远程恢复或真实 Vercel 生产权限。

公开行为数据无法做到绝对防伪；同源检查、输入白名单、数据库限流和事件去重用于减少噪声。限流键是逐分钟变化的 HMAC 摘要，清理任务删除过期项；目前为每来源地址每分钟最多 120 批、每批最多 12 个事件。

服务器错误只向访客返回状态码，不输出密钥、客户信息或数据库细节。密码、邮箱、表单内容不进入统计；仅有可选统计许可的成功询盘才会被关联。因此该看板不能替代邮件收件核对或正式询盘 CRM。
