## 发现并处理的问题

| 问题 | 处理及核验 |
| --- | --- |
| /products/toString 返回 500，错误 canonical 指向 undefined | 产品字典改为无原型对象；线上复验变为 404，正常三款产品仍为 200 |
| 联系页没有 h1 | 标题组件支持 h1，联系页线上检查为一个 h1 |

| 返回顶部隐藏后仍可进入 Tab 顺序 | 按可见性更新 aria-hidden 和 tabIndex；实际点击回到 scrollY=0，隐藏后 tabIndex=-1 |
| 首页及独立页缺少 canonical，产品标题重复品牌、用途不清晰 | 补齐 canonical；首页和每款产品新增后台 SEO 标题/摘要，保留原宣传大标题 |
| sitemap 每次构建把全部 lastmod 写成当前时间 | 移除不准确日期，保留有效正式地址 |
| 成功页允许收录；后台配置缺禁止收录响应头 | 成功页 noindex/follow；管理页和配置/API noindex；管理静态文件 no-store 防旧配置缓存 |
| 异常列表可能导致后台报错；死链接要等构建时才发现 | 保存前检查结构、站内地址/首页锚点、编码路径穿越、SEO 长度；可选空列表前台容错 |
| 询盘缺少字段长度上限和服务端空白处理 | 服务端 trim、合理长度限制及姓名/公司换行控制；错误数据不调用邮件服务 |
| 宣传插画被描述成实际报告界面 | 保留现有素材版式，将介绍及图片说明改为评估视角示意 |
