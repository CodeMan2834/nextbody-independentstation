# NEXBODY 网站运维操作手册

更新：2026-10-18。推荐使用 HTML 版：https://nexbodyfit.com/admin/manual.html

## 登录后台

1. 打开 https://nexbodyfit.com/admin/index.html。
2. 依次点击“进入 GitHub 登录”“使用 GitHub 登录”，使用自己的账号登录。
3. 左侧选择栏目，再点击内容条目。首次使用先把 GitHub 用户名发给负责人开通权限。

## 找到要改的内容

| 要改什么 | 后台位置 |
| --- | --- |
| 首页文字、轮播 | 首页内容 → 首页主要内容 → 对应板块 |
| 产品介绍、图片、参数、下载 | 产品管理 → 产品目录 → 产品列表 → 对应产品 |
| 新增案例、调整顺序 | 应用案例 → 案例列表 |
| 邮箱、导航、咨询按钮 | 全站设置 → 联系信息与社交账号 |
| 联系页等页面文字 | 独立页面 → 页面文案 |
| 搜索标题、摘要 | 全站设置或产品内 → 搜索引擎展示（SEO） |

新增产品、修改网址、布局或权限，请联系技术负责人。隐私与条款经负责人确认后发布。

## 更换素材

1. 点击图片或文件字段，上传并选中文件。
2. 图片使用 JPG、PNG 或 WebP；说明书使用 PDF。
3. 视频使用 MP4，并设置封面；轮播每条先选图片或视频类型。
4. 拖动列表条目调整顺序，新增案例的编号保持唯一。

## 发布与检查

1. 点击“发布 → 立即发布”。
2. 看到“本次内容已保存”后，等待网站更新；有部署查看权限时核对 Ready。
3. 打开正式网站，刷新并检查电脑和手机：文字、图片、视频、按钮和下载链接。
4. 继续修改时点击“重新载入，继续维护”；完成后点击“退出 / 结束编辑”。

保存成功后，官网需要等待部署更新。修改联系邮箱后，提交测试询盘并确认收件。

## 遇到问题

- 无法登录：重新登录；仍失败，把用户名和错误截图发给负责人。
- 发布失败：按红色提示修正字段；仍失败，保留文案和截图并联系技术负责人。
- 官网没更新：等待后刷新；仍没变，提供修改栏目、发布时间和截图。
- 素材打不开：重新选择素材、核对文件类型，再发布检查。
- 询盘没收到：检查 info@nexbodyfit.com 及垃圾邮件；记录提交时间交负责人排查。
- 需要恢复旧内容：联系技术负责人，说明页面、内容及时间。
